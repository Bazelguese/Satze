# Checklist QA UI (prima di condividere)

## Foundations

- [ ] Tutti i colori principali sono variabili, non valori hardcoded.
- [ ] Scala tipografica completa e coerente.
- [ ] Spacing usa solo scala 4pt definita.
- [ ] Radius e ombre applicati in modo consistente.

## Componenti

- [ ] Ogni componente chiave ha stati base (default, hover, disabled).
- [ ] Le varianti principali sono presenti (taglia/tipo/stato).
- [ ] Naming Figma consistente con `Satze/Khemet/...`.
- [ ] Auto-layout attivo nei componenti principali.

## Accessibilita e leggibilita

- [ ] Contrasto testo sfondo almeno AA.
- [ ] Testi piccoli (`caption`) ancora leggibili in dark mode.
- [ ] Focus ring visibile su elementi interattivi.

## Coerenza prodotto

- [ ] Card, deck panel e HUD usano lo stesso linguaggio visivo.
- [ ] Accenti oro/ciano usati solo per segnali importanti.
- [ ] Nessun eccesso di glow o effetti decorativi che riducono chiarezza.

## Pronto per handoff

- [ ] Pagina "Foundations" pulita e documentata.
- [ ] Pagina "Components" con varianti complete.
- [ ] Pagina "Examples" con almeno 2 schermate composte.
- [ ] Note finali con decisioni e prossimi step.
