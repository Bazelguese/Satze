# Satze Menu — UI Kit

Interactive recreation of the Satze main menu. Based on `Satze/src/components/menu/SatzeMenuPrototype.jsx` and `MenuScreenLayout.jsx`.

**Surfaces covered:**
- Main menu (banner buttons over cosmic background)
- Campaign hub (mission cards tagged by mission type)
- Army picker (8 factions with mood backgrounds)
- Loading / splash

**Components:**
- `CosmicBackground.jsx` — starfield + vignette + faux particle layer
- `BannerButton.jsx` — the trapezoid/banner-shaped menu button
- `MenuLayout.jsx` — shared background frame
- `SatzeWordmark.jsx` — logo treatment
- `ArmyTile.jsx` — faction picker tile
- `MissionCard.jsx` — campaign mission card with ASS/DIF/DOM/ANN/SPC tag
- `LoadingScreen.jsx` — HUD tactical splash

Open `index.html` for an interactive walkthrough: splash → main menu → campaign / army picker.
