# Prompt Midjourney per Icone Personalizzate

## 🎨 Parametri Base per Tutte le Icone

Aggiungi sempre questi parametri alla fine di ogni prompt:
```
--style raw --ar 1:1 --v 6.2 --stylize 100
```

**Spiegazione parametri:**
- `--style raw`: Stile più pulito e preciso, ideale per icone
- `--ar 1:1`: Aspect ratio quadrato (perfetto per icone)
- `--v 6.2`: Versione più recente di Midjourney
- `--stylize 100`: Bilanciamento tra creatività e fedeltà al prompt

## 🎯 Suggerimenti per Migliori Risultati

### 1. Iterazione e Refinement
- Inizia con il prompt principale
- Se il risultato è troppo complesso, aggiungi: `--stylize 50` (più semplice)
- Se è troppo semplice, aggiungi: `--stylize 200` (più dettagliato)

### 2. Modificatori Utili
- `minimalist` - Sempre incluso per semplicità
- `vector art style` - Per stile vettoriale pulito
- `clean lines` - Per linee nitide
- `simple geometric shapes` - Per forme riconoscibili
- `scalable icon` - Per ricordare a MJ che deve scalare bene

### 3. Colori Specifici
- Usa sempre i codici colore esatti (#a78bfa, etc.) nel prompt
- Puoi anche specificare: `purple and indigo palette` se MJ non riconosce l'hex

### 4. Post-Processing
Dopo la generazione:
1. Usa `--upscale` per ottenere risoluzione più alta
2. Converti in SVG con strumenti come:
   - **Vectorizer.io** (online)
   - **Adobe Illustrator** (Image Trace)
   - **Inkscape** (Path > Trace Bitmap)
3. Ottimizza il SVG con **SVGO** o **SVGOMG**

### 5. Alternative se Midjourney Non Funziona
Se i risultati non sono abbastanza "iconici":
- Prova **DALL-E 3** con prompt simili
- Usa **Stable Diffusion** con modelli come "Icon Diffusion"
- Considera **Figma** o **Adobe Illustrator** per creare manualmente partendo da ispirazioni

---

## 📐 Formato Finale

Una volta ottenuta l'icona:
1. **Ridimensiona a 512x512 px** (o mantieni la risoluzione originale se è più alta)
2. **Converti in SVG** se possibile
3. **Ottimizza** il file
4. **Testa** a diverse dimensioni (16px, 24px, 48px, 128px)

---

## 🔄 Workflow Consigliato

1. **Genera 4 varianti** con Midjourney usando il prompt principale
2. **Scegli la migliore** e fai upscale
3. **Converti in SVG** (se era PNG/JPG)
4. **Pulisci il codice SVG** (rimuovi elementi non necessari)
5. **Testa nel componente Icon** a diverse dimensioni
6. **Aggiusta colori** se necessario (usa il prop `color` del componente)
